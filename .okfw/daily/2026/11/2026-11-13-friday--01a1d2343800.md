## Notes

- A static pattern rule becomes one explicit rule for each target at read time ([ADR-0022](/decisions/adr-0022-a-static-pattern-rule-gives-one-explicit-rule-per-target--01a1d4cdf854.md)). The graph and the executor need no new rule kind.
- GNU Make keeps a target that the pattern does not match. The target gets the recipe, no prerequisites, and its name as the stem. zmake does the same.
- `$|` was always empty before this phase. Scenario 21 found it.

- The first macOS acceptance run failed 22 checks. Each came from one bug: the macOS file system ignores case, and zmake trusted `access`. GNU Make compares names through a cached directory listing ([ADR-0023](/decisions/adr-0023-the-acceptance-suite-runs-on-macos-against-gnu-make-4-3--01a1d4ecd992.md)).
- The case-insensitive test change of commit 320d2bc was wrong. The test compares the exact name again.
