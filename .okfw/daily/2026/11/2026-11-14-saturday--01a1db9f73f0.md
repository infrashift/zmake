## Notes

- GNU Make 4.3 prints the version for `-v`, `--version` and clusters such as `-nv`, and exits 0. It ignores the targets and `-C`. With `-h`, it prints the version and then the usage. zmake does the same.
- Zig 0.17 caches the configure phase. A git command in `build.zig` gives a stale commit unless `build.zig` poisons the cache ([ADR-0025](/decisions/adr-0025-the-version-line-names-the-git-commit-of-the-build--01a1db9effa4.md)).
- Without a `.git` check, git finds a parent repository of an unpacked tarball and gives the wrong commit.
- `-dirty` follows `git describe --dirty`: an untracked file does not add the suffix.
