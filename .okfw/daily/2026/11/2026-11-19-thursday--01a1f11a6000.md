# 2026-11-19 Thursday

- [x] Phase 25: the man pages `zmake(1)` and `zmakefile(5)`, installed by `zig build -p PREFIX` (ISSUE-025).

## Notes

- Question: where do the man pages go when the binary is in `~/.local/bin`? Answer: `~/.local/share/man`. man-db, macOS `man` and FreeBSD `man` search `../share/man` for each `bin` directory on the `PATH` when `MANPATH` is not set.
- man-db `manpath(5)` and the macOS `manpath(1)` page state the rule. A set `MANPATH` turns it off. A leading or trailing colon adds the default path back.
- `zig build -p PREFIX` already writes `PREFIX/bin/zmake`, so two `installFile` calls in `build.zig` are sufficient.
- The pages use mdoc. `make lint` checks them with mandoc, or with `groff -ww` when mandoc is not available.
- `scripts/ste-check.py` now reads the text of the pages. A line of a code macro, for example `Fl`, counts as one word.
